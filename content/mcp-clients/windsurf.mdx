Windsurf takes `serverUrl` for a remote server. Save the file and restart Windsurf so Cascade picks the server up.

## Sign in

Windsurf supports OAuth for remote servers. When it connects to Stunt Double, your browser opens on the Stunt Double sign-in page: sign in, review the scopes the consent screen lists, and approve. The [overview](/mcp#authentication) explains each scope.

## Check it works

- Open the **...** menu in the Cascade panel and look under **MCPs**: Stunt Double should be listed with a count of its enabled tools and its toggle on.
- Ask Cascade: "List my Stunt Double workspaces."

## Troubleshooting

- **Tools missing because of the 100-tool limit:** Cascade can use at most 100 tools across all your servers at once, and Stunt Double brings dozens. Turn off the ones you don't need with a `disabledTools` list in the server's block, or connect to the on-demand endpoint in [Connect](/mcp/connect#endpoints), which lists only a few core tools and loads the rest as a task needs them.
- **Server blocked on a team plan:** once a team admin allowlists any MCP server, the rest are blocked. The server ID they allowlist must match the key in your config exactly (`stuntdouble`).
- **Enterprise:** MCP may be off until you turn it on in Windsurf's settings.
