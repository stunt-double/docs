# Test a product behind your firewall

If the product you want to test is only reachable inside your network, a
cloud browser can't reach it. A device is a Mac on your side of the firewall
running the Stunt Double app, so actors browse from there without you opening
anything up.

<Callout variant="note" title="Startup plan and above">
  Devices are available on the Startup plan and above. A workspace owner or admin switches
  them on, then any member can set up their own Mac.
</Callout>

## Turn devices on

Open **Settings > Devices** and switch on **Use devices in this workspace**.
On other plans, this page explains what devices do and how to upgrade.

## Set up a Mac

1. On a Mac that can reach your internal product, download the Stunt Double
   [desktop app](/integrations/desktop-app), open it and sign in. Google
   Chrome needs to be installed.
2. Open **Go > This Device** (Cmd+D) and click **Set up this Mac**.
3. Wait for the device console to show **Connected**.

The app dials out to Stunt Double rather than waiting for an inbound
connection, so your firewall needs no changes. If your product sits behind a
VPN portal or SSO, sign in once in the device console. The sign-in persists
for later runs.

## Choose where each actor's browser runs

Open an actor, go to its **Manage** tab and find **Where this actor's browser
runs**:

- **Stunt Double cloud** for public sites.
- **Any device in this workspace** to use whichever device is online.
- **A named device** to always use that Mac.

An actor set to a device never falls back to the cloud: if its device is
offline, the run stops and tells you. An actor set to the cloud never opens an
internal site: if the project is marked internal, or the address only works
inside your network, the run stops and asks you to choose a device.

## Control what it can reach

Each device has an access setting in **Settings > Devices** with three modes:

- **Allow all domains**: no restriction.
- **Allow specific domains**: only the domains you list.
- **Block specific domains**: everything except the domains you list.

A new device starts on Allow all domains, so it works as soon as it connects.
To restrict it, switch to Allow specific domains and list only what your
actors need to reach.

## Watch status live

Devices show their status live everywhere they appear: Settings, the actor's
Manage tab and the device console. A Mac that stops checking in turns Offline
within a couple of minutes, so you can tell before starting a run that depends
on it.
