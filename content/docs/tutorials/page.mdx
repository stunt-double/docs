# Tutorials

The **[Quickstart](/support/docs/getting-started)** gets you from an empty
workspace to a first checklist run, and **[Core concepts](/support/docs/concepts)**
explains what each building block does. These tutorials go further: practical,
task-oriented guides for getting real value out of each part of the product as
your usage grows.

## The series

1. **[Build an actor with the right capabilities](/support/docs/tutorials/first-actor)**
   Write instructions and knowledge that make an actor behave like a real
   member of your audience, and turn on only the capabilities it needs.
2. **[Write checklists that catch real regressions](/support/docs/tutorials/effective-checklists)**
   Structure checks around outcomes, not clicks, and read the evidence behind
   a pass or fail instead of trusting the badge.
3. **[Run a user interview](/support/docs/tutorials/running-an-interview)**
   Structure sections and items, recruit actor personas or real participants,
   and read an evidence-backed report.
4. **[Automate multi-step workflows](/support/docs/tutorials/building-workflows)**
   Chain checklists, conditions, notifications, and PR reviews into one
   repeatable automation.
5. **[Turn runs into insights](/support/docs/tutorials/reviewing-runs)**
   Read results, screenshots, and recordings like a teammate would, and see
   what surfaces automatically as an insight.
6. **[Collect stakeholder feedback on a prototype](/support/docs/tutorials/feedback-widget)**
   Install the feedback widget so reviewers pin comments in context, then
   triage, reply, and resolve them from the project.
7. **[Review designs from Slack](/support/docs/tutorials/slack-design-review)**
   Share a link in Slack and get the screen opened, reviewed, and written up in
   the thread, then ask the agent to run the rest of your workspace.
8. **[Test a product behind your firewall](/support/docs/tutorials/self-hosted-worker)**
   Run actors against an internal product with a self-hosted worker, no
   inbound firewall changes required.
9. **[Automate Stunt Double from Claude](/support/docs/tutorials/automate-with-mcp)**
   Connect the MCP server to Claude and drive actors, checklists, and
   interviews from a conversation.
