# Linear

Connect Linear and Stunt Double becomes a teammate on your issues. Assign an
issue to Stunt Double or mention it in a comment, and the agent works on it
and replies in the issue: it reviews designs, starts checklist and automation
runs, and answers questions about your workspace.

## What it does

- **The Stunt Double agent.** Delegate an issue to Stunt Double, or mention it
  in a comment, and the agent answers on the issue. Pick an actor for it to
  act as, and it uses that actor's model and MCP servers.
- **Design reviews.** Ask it to review the links in an issue. It opens each
  one in a real browser and replies with findings. A link only your network
  can reach opens on your own [device](/integrations/self-hosted-workers#pool-devices).
- **Runs on request.** Ask it to run a checklist or an automation, and it
  starts the run and tells you on the issue.
- **Workspace answers.** It can list the projects, actors, checklists and
  automations in your workspace.

## Before you start

- **Role.** Any member can connect Linear. Turning it on for the workspace and
  choosing the agent's actor takes an owner or admin.
- **Plan.** Free and Solo cannot connect Linear. Hobby can connect one of
  Linear or Slack, and Startup and above can connect both.

## Set it up

1. In [app.stuntdouble.io](https://app.stuntdouble.io), open **Integrations**
   from the sidebar and click **Linear**.
2. On **Your account**, click **Connect Linear** and approve Stunt Double in
   Linear. The step changes to **Connected as** with your Linear name.
3. On the step named after your workspace, an owner or admin turns the switch
   on. It reads **On for this workspace.**
4. On **Projects**, click **Choose for a project** and pick a project. Its
   **Settings** open on the **Integrations** tab: choose the project's Linear
   team there.
5. Under **Settings**, an owner or admin sets **Agent identity**. Pick an
   actor for the agent to act as, or leave it on **No actor** for the default
   model and built-in tools.

Then try it: open an issue in Linear and assign it to Stunt Double, or mention
Stunt Double in a comment.

To stop the agent partway through, use Linear's **Stop** control on the
agent session. Stunt Double ends that turn and hands the session back to you.

### Hand setup to someone else

At the foot of the Linear page, the **Install link** card has a link that
takes someone through connecting Linear, turning it on for this workspace,
choosing a team and the agent's actor. It picks up wherever they left off.

## What Stunt Double can access

Stunt Double asks Linear for these scopes:

| Scope             | Used for                                     |
| ----------------- | -------------------------------------------- |
| `read`            | Reading issues, teams and comments           |
| `write`           | Updating issues the agent works on           |
| `issues:create`   | Creating issues                              |
| `comments:create` | Replying on issues                           |
| `app:assignable`  | Letting you assign issues to Stunt Double    |
| `app:mentionable` | Letting you mention Stunt Double in comments |

<Callout variant="note" title="What the agent can use">
  With an actor set under **Agent identity**, the agent also uses that actor's
  model and MCP servers, including any credentials the actor holds. Choose an
  actor whose access you are happy to see used on Linear issues.
</Callout>

## Disconnect

- **Stop one workspace using Linear.** An owner or admin turns off the
  workspace switch.
- **Remove Linear from your account.** Click **Disconnect** on **Your
  account**. The **Disconnect Linear?** dialog lists every workspace that loses
  Linear. Confirm to remove it.
- **Remove the app from Linear.** You can also remove Stunt Double from the
  installed apps in your Linear workspace settings.

## Troubleshooting

**You cannot assign an issue to Stunt Double.** Check that Linear is on for
the workspace and the connection still shows **Connected as**. If it was
disconnected, connect it again.

**The agent replies with only its built-in tools.** **Agent identity** is set
to **No actor**. An owner or admin can pick an actor under **Settings**.

**Agent identity is missing.** It only appears to owners and admins, and only
once Linear is connected and on for the workspace.

**Linear will not let you install the app.** Adding apps to a Linear
workspace can be limited to Linear admins. Ask one to connect, or send them
the install link.

**The agent cannot find a checklist or automation.** Each issue is answered
from one Stunt Double workspace. If your Linear organization is turned on in
more than one, the agent may be working in a different one from the
checklist: turn Linear off in the workspaces that should not answer.
