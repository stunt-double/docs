# Figma plugin

The Stunt Double plugin brings actors into the Figma canvas. Select a frame
and actors review it, run a checklist against it, or answer your questions
about it, and the findings land on the canvas next to the design.

<Callout variant="note" title="Not in the Figma Community yet">
  The plugin is in early access and not listed in the Figma Community yet, so
  there is no public install link. This page describes how it works so you know
  what to expect when it arrives.
</Callout>

## What it does

The plugin has four tabs:

- **Review.** Select a frame, pick the reviewers and, if you like, **Add
  instructions** to focus them. The plugin exports the frame and the actors
  judge the image. When the review finishes, **Place on canvas** adds each
  finding as a native Figma annotation on the layer it is about, and **Place
  as layer** (under **More actions**) draws numbered pins and a findings panel
  instead. **Resolve** findings as you fix them, then click **Re-check** to ask
  the reviewers what is fixed. **Ask an actor** opens a conversation with one
  of your actors about the reviewed frame.
- **History.** Every review in the project, newest first. Select a reviewed
  frame on the canvas and the bar offers **Last review** to jump to it.
- **Checks.** Run one of the project's checklists against up to six selected
  frames, taken in flow order, or click **Run on** the project's address to
  run it in a real browser. **Test the prototype** takes a prototype or Make
  link and opens a new interview for it in Stunt Double.
- **Feedback.** Leave a note on the selected frame or the whole file, with
  **Attach a snapshot** to send the frame along, and filter the list to **This
  file only** or the whole project.

The plugin also adds **Review selection**, **Run checklist on selection**,
**Leave feedback on selection** and **Open Stunt Double** to Figma's plugin
menu. A reviewed frame gets an **Open review** button in Figma's properties
panel, so anyone can get back to its findings.

## Before you start

- **A Stunt Double account** with access to the workspace you want to work
  in. If you have none, the plugin offers **Create workspace**.
- **Actors in the workspace.** Reviews need at least one actor. Create one in
  the dashboard if the plugin says **No actors in this workspace yet.**

## Connect the plugin

The plugin signs in through your browser, so it never asks for a password.

1. In a Figma design file, open **Stunt Double** from the Plugins menu and
   click **Connect**. A browser tab opens and the plugin shows a confirmation
   code.
2. In the browser, sign in to Stunt Double if you are not already. The
   **Connect the Stunt Double plugin** page shows the same code and lists what
   the plugin will be able to do. If the codes do not match, do not approve:
   the request did not come from your Figma.
3. Click **Approve**. To sign in as someone else, click **Use a different
   account** first.
4. Back in Figma, link the file to a project: pick one, or create a project
   for the file. A new project starts with a starter checklist and actors.

The link is stored in the file, so everyone who opens it with the plugin
lands in the same project. To change it later, open the workspace and project
view from the plugin's header, where you can also see the project's rules,
paste the file's Figma link so findings link back to it, or unlink the file.

## What the plugin can access

When you approve, the plugin can:

- Run design reviews on frames you select
- Run checklists against your frames
- Read and leave feedback on your projects
- Ask actors about a frame

Approving issues a plugin token that lasts 90 days and is stored in Figma on
your machine. The plugin can only reach `app.stuntdouble.io`.

The plugin does not need the [Figma workspace connection](/integrations/figma),
and the connection does not need the plugin. Use either or both.

## Disconnect

Open the account menu in the plugin and click **Sign out**. That revokes the
token and removes it from Figma on your machine. You can also revoke it from
your account settings in Stunt Double, under **Connected apps**. The token
expires on its own after 90 days, and the plugin asks you to connect again.

## Troubleshooting

**"That request expired. Connect again."** The browser approval took too
long. Click **Connect** again and approve within a few minutes.

**"You denied the connection."** Someone clicked **Deny** in the browser.
Connect again and click **Approve**.

**The browser says the connect request is no longer valid.** The request was
already used or has expired. Return to Figma and start the connection again.

**"Text cannot be reviewed. Select the frame around it."** Reviews and
checklists run on frames, not on text, shapes or Stunt Double's own layers.
Select the frame that contains them.

**"That frame is too large."** Select a smaller frame or a section of it.
Very tall frames reach the actors small, so a section reviews better anyway.

**A banner reads "Cannot reach Stunt Double. Retrying."** The plugin lost its
connection and reconnects by itself. If it never recovers, check your
network: Figma only lets the plugin talk to `app.stuntdouble.io`, so a
network that blocks it will stop the plugin.
