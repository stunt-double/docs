# Desktop app

The desktop app is Stunt Double in its own Mac window. It can also make your
Mac a [device](/integrations/self-hosted-workers), so actors browse with this
computer's Chrome, including its VPN access and machine-credential sign-ins.

## Before you start

- **macOS.** macOS 10.15 or later, on Apple silicon or Intel.
- **Chrome.** Google Chrome installed, if you want to use the Mac as a
  device.
- **Plan.** The app itself works on any plan. Using the Mac as a device needs
  the Enterprise plan, with devices switched on by an owner or admin in
  **Settings**, then **Devices**.

## Install it

1. Go to [stuntdouble.io](https://stuntdouble.io) and click **Download for
   Mac**.
2. Open the download and drag Stunt Double into **Applications**.
3. Open the app and sign in with your Stunt Double account.

The app updates itself when a new version ships.

## Use this Mac as a device

1. In the app, open **Go**, then **This Device** (Cmd+D). The device console
   opens in its own window.
2. Click **Set up this Mac**. The console shows **Connected** once the Mac
   checks in.
3. Choose where each actor's browser runs. Open an actor, go to its **Manage**
   tab and, under **Where this actor's browser runs**, choose this Mac or
   **Any device in this workspace**.

The browser runs inside the app, not as a window on your desktop. Use the
device console to watch what an actor is doing, sign in to an internal site or
take control of the browser. Sign-ins you make there persist for later runs.

Setting up is remembered. When the app restarts, including after an update,
the Mac reconnects by itself. Quitting the app closes its browser.

To stop, click **Disable this device** in the console. A run already in
progress stops with it.

## Troubleshooting

**This Device asks you to install Google Chrome.** The device drives Chrome.
Install it, then click **Set up this Mac** again.

**The console says this Mac is paired with another workspace.** A Mac belongs
to one workspace at a time. Click **Move to** and confirm to move it here.
Runs in the other workspace stop using it.

**The console says "This device is no longer paired".** The device was removed
from the workspace, or its key no longer works. Click **Pair again**.

**The console says "Not reaching Stunt Double".** The app is running, but
Stunt Double has not heard from it for over a minute. Check the Mac is online,
then click **Reconnect**.

**The console says to update the app.** That version cannot run a device yet.
Update the app and reopen **This Device**.

**A run says the browser was suspended by security software.** Endpoint
security on the Mac froze Chrome before it could start. Ask your IT team to
allow Stunt Double to launch Google Chrome.

**A run says the browser profile is in use.** Only one Chrome can use the
device's profile at a time. Close any Chrome window still open on that
profile, such as a sign-in window, and try again.
