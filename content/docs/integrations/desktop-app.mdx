# Desktop app

The desktop app is Stunt Double in its own Mac window. It can also turn your
Mac into a worker, so actors browse with this computer's Chrome, including its
VPN access and machine-credential sign-ins.

## Before you start

- **macOS.** macOS 10.15 or later, on Apple silicon or Intel.
- **Chrome.** Google Chrome installed, if you want to use the Mac as a
  worker.
- **Plan.** The app itself works on any plan. Using it as a worker needs the
  Workers entitlement, which comes with the Enterprise plan.

## Install it

1. Go to [stuntdouble.io](https://stuntdouble.io) and click **Download for
   Mac**.
2. Open the download and drag Stunt Double into **Applications**.
3. Open the app and sign in with your Stunt Double account.

The app updates itself when a new version ships.

## Use this Mac as a worker

1. In the app, open **Settings**, then **Workers**.
2. Find **Use this device as a worker** and click **Enable this device**.
3. The card changes to **Connected using this machine's browser.** The
   worker shows in the list as **Your device**.
4. Assign actors to it. Open an actor, find **Self-hosted worker** and choose
   this device under **Worker**.

The browser runs inside the app, not as a window on your desktop. Click **Open
device console** to watch what an actor is doing, sign in to an internal site
or take control of the browser. Sign-ins you make there persist for later
runs.

Enabling is remembered. When the app restarts, including after an update, the
worker reconnects by itself.

To stop, click **Disable** on the same card.

## Troubleshooting

**There is no "Use this device as a worker" card.** The card only shows inside
the desktop app, in a workspace with the Workers entitlement.

**The card asks you to install Google Chrome.** The worker drives Chrome.
Install it, then click **Enable this device** again.

**The card offers "Pair with" your workspace.** This Mac is paired with a
different workspace, or its worker was deleted. Click **Pair with** to pair it
here.

**The card says to update the app.** That version cannot manage a worker yet.
Update the app and reopen **Workers**.

**A run fails because the browser profile is in use.** Only one browser can
use the profile at a time. Close any Stunt Double worker running on the same
Mac from the command line, or a sign-in window left open, and try again.
