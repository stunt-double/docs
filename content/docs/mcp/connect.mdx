Every client connects to the same server and signs in with OAuth the first time it needs your account. No API keys. This page covers what the Stunt Double app does for you and the endpoints on offer; the [client pages](/mcp/clients/claude-code) cover each client's own setup, sign-in and troubleshooting.

## From Integrations in your workspace

Open **Integrations** in your workspace. Four cards set up the MCP server, each showing the server URL with a copy button:

- **Claude.** The one-click Claude Desktop extension (below), plus the command for [Claude Code](/mcp/clients/claude-code).
- **ChatGPT.** The steps to add Stunt Double as an app in developer mode. See [ChatGPT](/mcp/clients/chatgpt-and-codex).
- **Cursor plugin.** The plugin with skills, rules and agents, and the repository to import as a team marketplace. See [Cursor](/mcp/clients/cursor).
- **MCP.** The JSON block for Windsurf and any other client that takes an `mcpServers` config. See [Windsurf](/mcp/clients/windsurf) and [other clients](/mcp/clients/other-clients).

### Claude Desktop

The **Claude** card has a **Download .mcpb** button. Open the file and Claude Desktop installs Stunt Double as an extension, with the connector registered for you. It needs Claude Desktop's extensions support and Node 18 or later on your machine. The first time Claude calls a Stunt Double tool, it opens a browser window for you to sign in. To add it as a custom connector instead, select **Add it manually instead**, or follow the [Claude](/mcp/clients/claude) page.

## Endpoints

| Endpoint                                     | What it serves                                             | Sign-in |
| -------------------------------------------- | ---------------------------------------------------------- | ------- |
| `https://app.stuntdouble.io/api/mcp`         | Every tool, prompt and resource your scopes allow          | OAuth   |
| `https://app.stuntdouble.io/api/mcp/dynamic` | The same server, with tools loaded on demand               | OAuth   |
| `https://app.stuntdouble.io/api/mcp/index`   | Three read-only [Stunt Double Index](/index-ranking) tools | None    |

**On demand.** If your client has no tool search of its own, or caps how many tools it can hold, use `/dynamic`. Its tool list carries `list_workspaces`, `list_projects` and `search` plus `find_tools` and `call_tool`, and the rest of the catalog loads only when a task needs it, so the whole catalog doesn't sit in the model's context on every turn.

**Index lookups with no account.** `/index` needs no sign-in and carries only `get_index_report`, `list_index_sessions` and `search_index_domains`. Add it like any other remote server, with authentication turned off where the client asks (in Claude, leave the OAuth fields empty; in ChatGPT, choose **No authentication**). In Claude Code:

```sh
claude mcp add --transport http stunt-double-index https://app.stuntdouble.io/api/mcp/index
```

Every scorecard on the Index has a ready-made prompt that asks about that site and tells your agent how to connect.

## What a connection can do

The consent screen names the client, lists the scopes it asked for with what each covers, and shows the account you're signed in as. A client that asks for no scope gets all three. Whatever it holds, a connection acts as you and reaches only the workspaces you belong to, and a scope it doesn't hold hides that scope's tools entirely. `mcp:run` also covers switching on an automation that runs on its own (on a schedule, webhook or event): a client without it can build one, but it is created paused. The `stuntdouble://connection` resource lists the scopes a connection holds and the tools each one unlocks. The [overview](/mcp#authentication) explains each scope, and [tools](/mcp/tools) lists what they unlock.

A connection lasts 90 days. After that the client asks you to sign in again, and the consent screen says **Reconnect** instead of **Approve**. Approving again while a connection is still live issues a fresh one; the old one keeps working until it expires.

## Revoke access

Go to **Account**, then **Security**, and find the client under **Connected apps**. Revoke it there to end that client's access to your account, or revoke every connection at once.
