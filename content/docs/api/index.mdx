# Stunt Double API

Stunt Double exposes its platform through a **Model Context Protocol (MCP)**
server at `https://app.stuntdouble.io/api/mcp` (Streamable HTTP, OAuth 2.1).
Drive your workspace from Claude, your own agents or any MCP client, without
writing a bespoke integration.

- **[MCP server](/mcp)**: authentication, scopes and what a connection can reach.
- **[Connect](/mcp/connect)**: set up Claude, Cursor, ChatGPT and other clients.
- **[Tools](/mcp/tools)**: every tool, prompt and resource, grouped by what it acts on.

## Public docs server

Agents that haven't signed in can still connect. A read-only MCP server at
`https://www.stuntdouble.io/api/docs-mcp` needs no authentication and exposes
the documentation as resources. It has no tools: to act on a workspace,
connect to the product server above.

## Versioning

A client negotiates the MCP protocol version at `initialize`. Breaking changes
ship alongside the old behavior, never in place, and deprecations are announced
in the [changelog](https://www.stuntdouble.io/changelog) at least 90 days
before removal.
