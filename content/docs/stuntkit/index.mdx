# StuntKit

Give your AI agent a browser it can use safely. StuntKit is the toolkit Stunt
Double runs on every agent session: browser tools for your own agents, plus the
icons, spelling (Americanize) and accessibility packages behind the product.

It is licensed under Apache-2.0, at
[github.com/stunt-double/stuntkit](https://github.com/stunt-double/stuntkit).
StuntKit packages are published to GitHub Packages, which asks for a token even
for public packages.

## How to use it

- **Build your own browser agent.** Add `@stunt-double/browser-toolset` to an
  agent loop, connect it to Playwright, a hosted browser or a CDP client, and
  turn on the guards. See [Give an AI agent a safe browser](/stuntkit/browser-toolset).
- **Run Stunt Double sessions on your own network.** A Mac running the
  Stunt Double app runs actors inside your network, so they can reach staging
  and internal tools. See [Test a product behind your firewall](/tutorials/self-hosted-worker).
- **Make a site work for agents.** Drop the `@stunt-double/wao` script into a
  page to repair the accessibility tree agents read.
- **Match the product in your own UI.** Use `@stunt-double/icons` for the
  Continuity icons and Americanize (`@stunt-double/spelling`) to localize copy.

## Principles

- **Rules live in the tools, not the prompt.** A prompt that says "never pay or
  sign up" is a request a model can ignore. When a StuntKit guard refuses, the
  click never reaches the page.
- **Bring your own model and browser.** The tools never call a model and have
  no runtime dependencies. Your agent does the reasoning; you choose the
  browser.
- **Guards are opt-in and readable.** Turn on the ones you need, and read and
  test every rule before an agent acts on a real site.
- **One codebase.** The packages are the same code that drives hosted Stunt
  Double actors and the [Stunt Double Index](https://index.stuntdouble.io).

## Contribute

Issues and pull requests are welcome on the repository. It has a
`CONTRIBUTING.md` with the local setup, and every commit needs a
[Developer Certificate of Origin](https://developercertificate.org) sign-off
(`git commit -s`). Report security issues privately through GitHub rather than
in a public issue.

<Callout variant="tip" title="Using StuntKit with Stunt Double">
  You don't need StuntKit to use Stunt Double: hosted actors already run on it. Reach for it when
  you are building an agent of your own, or when you want to run Stunt Double sessions on your own
  infrastructure.
</Callout>
