# StuntKit

Give your AI agent a browser it can use safely. StuntKit is the open source
toolkit behind Stunt Double: the browser tools every actor and Stunt Double
Index session runs on, plus the icons, spelling and agent-readiness packages
behind the product.

It is licensed under Apache-2.0, at
[github.com/stunt-double/stuntkit](https://github.com/stunt-double/stuntkit).
The packages are published to GitHub Packages, which asks for a GitHub token
with `read:packages` even for public packages. Each package page has its own
install steps.

## Agent skills

Each package has an Agent Skill that teaches a coding agent when to reach for
it, how to wire it up and the mistakes to avoid, plus skills for choosing a
package and making a site agent-ready, and agents that build and review
browser agents. Install them all in Claude Code as a plugin:

```sh
/plugin marketplace add stunt-double/stuntkit
/plugin install stuntkit@stuntkit
```

Other agents that read `SKILL.md` folders can copy them from the repository's
[`skills`](https://github.com/stunt-double/stuntkit/tree/main/skills) folder.

## Principles

- **Rules live in the tools, not the prompt.** A prompt that says "never pay or
  sign up" is a request a model can ignore. When a StuntKit guard refuses, the
  click never reaches the page.
- **Bring your own model and browser.** No package calls a model or needs a
  runtime dependency. Your agent does the reasoning; you choose the browser.
- **Guards are opt-in and readable.** Turn on the ones you need, and read and
  test every rule before an agent acts on a real site.
- **One codebase.** Stunt Double ships the same packages: hosted actors and
  the [Stunt Double Index](https://index.stuntdouble.io) run on the browser
  toolset, and the product uses the icons and Localeizer.

## Contribute

Issues and pull requests are welcome on the repository. It has a
`CONTRIBUTING.md` with the local setup, and every commit needs a
[Developer Certificate of Origin](https://developercertificate.org) sign-off
(`git commit -s`). Report security issues privately through GitHub rather than
in a public issue.

<Callout variant="tip" title="Using StuntKit with Stunt Double">
  You don't need StuntKit to use Stunt Double: hosted actors already run on it.
  Reach for it when you are building an agent of your own, or making your own
  site easier for agents to use.
</Callout>
