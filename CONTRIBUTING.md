# Contributing

Fixes and improvements are welcome.

1. Fork the repo and create a branch.
2. Edit the MDX under `content/docs/`. Pages from `stuntdouble-mcp` or `stuntkit` are generated: open the change in that repo instead.
3. Run `pnpm test`, `pnpm type-check` and `pnpm build`.
4. Open a pull request describing what changed and why.

Style:

- American English spelling.
- No em dash characters. Use commas, colons, parentheses or full stops. CI checks this.
- Keep examples runnable and free of real keys or tokens.
